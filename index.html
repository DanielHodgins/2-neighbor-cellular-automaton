2-Neighbor Cellular Automaton

Exactly 2 neighbors → alive. Anything else → dead.

Generation: 0 / 100 Alive: 0

How to use

  • Click cells to turn them on or off.
  • Start runs the simulation.
  • Step advances one generation.
  • Back goes back one generation.
  • Reset returns to your original grid.
  • Clear clears the current grid.

Keyboard: Space Start/Pause ← Back → Step
